# ⏰ time_event

一个用 Rust 编写的秒级定时任务工具，类似于 Linux 下的 cron。支持间隔任务与定点任务两种模式，命令通过当前用户的 Shell 执行并继承其环境变量，配置文件支持热加载。

## 主要特性

- 🦀 纯 Rust 实现，单进程守护，资源占用低
- 📝 简单的自定义配置格式，支持间隔执行与固定时间执行
- 🔄 配置文件热加载，修改后自动生效，无需重启
- 🧑‍💻 命令通过当前用户的 Shell（读取 `SHELL` 环境变量，默认 `/bin/sh`）执行，继承用户环境
- ⏱️ 秒级调度精度
- 📜 错误输出自动写入日志文件，便于排查

## 构建与运行

```bash
cargo build --release
./target/release/time_event
```

首次运行会自动创建配置文件并写入示例模板。

## 配置文件

- 配置路径：`~/.config/time-event/te.conf`
- 日志路径：`~/.config/time-event/te.log`

每行一个任务，以 `*` 或 `:` 开头（英文符号），其余行（如 `#` 注释）会被忽略。

### 间隔任务（`*` 开头）

格式：`* 是否启动时执行(y/n) 秒 分 时 天 月(30天) 命令`

```
* y 3 * 1 0 2 echo 'hello world'
```

- `*` 与 `0` 含义相同，表示该字段为空（按 0 计）
- 所有时间字段全为 `*` 时，每秒执行一次
- 第二字段以 y/Y 开头时，程序启动后立即执行一次，之后每隔设定间隔执行一次；否则只在间隔到达时执行
- 上面示例表示：启动后立即执行一次，之后每隔 3 秒 + 1 小时 + 2×30 天 执行一次 `echo 'hello world'`

### 定点任务（`:` 开头）

格式：`: 运行时间 启动补跑时限(n 或 同格式时间) 命令`

```
: 30:15 n echo 'Hello rust'
: 12:30:0 13:0:0 ~/script.sh
```

- 运行时间按字段数量支持五种格式：`秒`、`分:秒`、`时:分:秒`、`天:时:分:秒`、`月:天:时:分:秒`
- 第一行表示每小时的 30 分 15 秒执行一次，不启用启动补跑
- 第二字段为 n/N 时不补跑；否则程序启动时，若当前时间晚于运行时间且早于该时限，则立即补跑一次（第二行：启动时若处于 12:30:00 ~ 13:00:00 之间则强制执行一次）

## 工作机制

- 程序启动后通过 notify 监控配置文件所在目录，文件变更后自动重新加载所有任务
- 每秒检查一次所有任务，条件满足时通过 Shell 执行对应命令
- 命令以子进程方式启动，并在独立线程中等待回收，避免僵尸进程累积
- stderr 被重定向到日志文件 `te.log`，配置错误与运行错误都会记录其中


## 注意事项

- 间隔任务的计数以程序启动时刻为基准，而非自然时间的整点
- "月"按 30 天（2592000 秒）计算
